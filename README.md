#  Temperature Converter Website

A user-friendly and responsive **Temperature Converter** built with **HTML**, **CSS**, and **JavaScript**!  
Convert between Celsius and Fahrenheit effortlessly with a clean, intuitive UI. ❄️🔥

---

##  Features

-  Input temperature in either **Celsius** or **Fahrenheit**
-  Real-time conversion with instant results
-  Input validation (e.g., handles empty or invalid entries)
-  Clean, responsive UI for all screen sizes  (desktop & mobile)
-  Lightweight frontend—no dependencies needed 

---

##  Tech Stack

-  **HTML** — Page structure & input elements  
-  **CSS** — Styling, layout, and responsiveness  
-  **JavaScript** — Conversion logic & interactivity

*(Project languages: ~44% CSS, ~31% HTML, ~25% JavaScript)*
